# 《异环》介绍
![封面](cover.jpg)

## 游戏简介
《异环》是Hotta Studio制作的超自然都市开放世界RPG游戏。故事发生在海特洛市，玩家的身份是鉴定师，也是一名无证的异象猎人，加入古董店“伊波恩”，接各种异象委托，在城市里探索谜团。

## 世界观
海特洛市是一座现代都市，但是城市里面藏着很多异象、奇点，这些是超自然现象。
玩家一边体验普通都市生活，一边调查各种诡异事件，和店里的伙伴一起冒险。

## 核心玩法
1. 都市开放世界自由探索，可以开车、逛街道、逛商店
2. 异象战斗，不同角色拥有异能，组队战斗
3. 角色养成，抽取、培养不同的伙伴
4. 都市生活玩法：买房、装修、改装载具、逛街
5. 主线剧情+角色个人故事，体验都市奇幻故事

## 主角与伊波恩
![浔](xun.jpg)
浔是伊波恩古董店的店长，性格随性，带着一群伙伴接异象委托。
店里的成员性格各不相同，每个人都有自己的过往和秘密。

## 总结
《异环》把现代都市和超自然奇幻结合，既有开放世界的自由探索，也有细腻的角色剧情，都市氛围感很强。
